Создай полноценный backend-проект на Java 21 с использованием фреймворка Vert.x 5.1.6 и системы сборки Gradle. 
Проект должен реализовывать сценарий «Фоновая обработка задач» (Background Task Processing) с асинхронным уведомлением 
о прогрессе через WebSocket.

# Требования

1. **Серверная часть**: Vert.x
2. **Интерфейс**: обращение через REST-клиент
3. **Асинхронное взаимодействие**: сервер должен поддерживать асинхронную обработку запросов(WebSocket)
4. **База данных**: приложение должно взаимодействовать с БД PostgreSQL(18.6), хранить данные пользователей, сообщения, статусы задач и т.д.
5. **Сборка**: для сборки приложения использовать Gradle
6. **Контейнеризация**: Предусмотреть Dockerfile и docker-compose

# Кейс

**Фоновая обработка задач**: пользователь через интерфейс (или API) запускает задачу с имитацией прогресса, 
сервер уведомляет о ходе выполнения через сокеты. 
Важно, чтобы несколько пользователей могли запускать свои задачи и получать только свой прогресс.
